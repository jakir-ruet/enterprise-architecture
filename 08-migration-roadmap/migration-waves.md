# Migration Waves

## Wave 0 — Discover and Baseline

- validate current architecture
- inventory applications
- validate integrations
- validate data model
- document dependencies

## Wave 1 — Stabilize

- security baseline
- logging/monitoring
- deployment controls
- backup/recovery validation

## Wave 2 — Modernize

- improve API architecture
- reduce technical debt
- improve integration patterns
- improve operational resilience

## Wave 3 — Optimize

- selective service extraction where justified
- performance optimization
- cost optimization
- advanced analytics/automation

Each wave requires explicit entry/exit criteria and architecture approval.
